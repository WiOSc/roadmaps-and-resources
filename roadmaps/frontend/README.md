# Frontend Web Development Roadmap

> A beginner-friendly path to learn frontend web development by learning the fundamentals, building projects, and gradually working with modern frontend tools and frameworks.

## Prerequisites

No prior web development experience is required.

You should be comfortable with:

* Using a computer and web browser
* Creating and managing files and folders
* Basic command-line usage is helpful, but not required

---

## Learning Path

### 1. HTML + CSS

#### Learn

[HTML + CSS Tutorial](https://youtu.be/HGTJBPNC-Gw?si=HWUpx1EZdUGjaZcI)

Start by learning how websites are structured and styled.

#### Build

Create a **Social Media Handles Page** containing links to all your social media profiles.

Try to make the page:

* Easy to navigate
* Responsive on different screen sizes
* Visually appealing
* Accessible and readable

#### You should learn

* HTML document structure
* Semantic HTML
* Headings, paragraphs, links, and images
* Forms and inputs
* CSS selectors
* Colors, fonts, spacing, and borders
* Flexbox
* Responsive design
* Basic accessibility

---

### 2. JavaScript

#### Learn

[JavaScript Tutorial](https://youtu.be/lfmg-EJ8gm4?si=3wX5i_pvYuZ4XJY7)

Learn how to make websites interactive and dynamic.

#### Build

Create a **Rock–Paper–Scissors Game** where the user plays against the computer.

Your game should:

* Accept the player's choice
* Generate a random computer choice
* Determine the winner
* Keep track of the score
* Display the result clearly

#### You should learn

* Variables and data types
* Functions
* Conditional statements
* Loops
* Arrays and objects
* Events
* DOM manipulation
* User input
* Basic debugging
* Modern JavaScript syntax

---

### 3. React

#### Learn

[React Tutorial](https://youtu.be/CgkZ7MvWUAA?si=K3nSmS6DXptgOVv)

Once you are comfortable with JavaScript, learn React to build interactive user interfaces using reusable components.

#### Build

Create a **Pomodoro Timer** inspired by [Pomodoro Timer](https://pomodorotimer.online/).

Your timer should include:

* Work and break sessions
* Start and pause controls
* Reset functionality
* A visible countdown
* A clean and responsive interface

#### You should learn

* Components
* JSX
* Props
* State
* Event handling
* Conditional rendering
* Lists and keys
* Hooks
* Component composition
* Basic React project structure

---

### 4. Next.js

#### Learn

[Next.js Tutorial](https://youtu.be/xnOwOBYaA3w?si=jnX1Z_Hv97WiGu3H)

Once you understand React, learn Next.js to build production-ready React applications with features such as routing, layouts, server-side rendering, and optimized deployment.

#### Build

Create and deploy your own **Portfolio Website** using Next.js.

Your portfolio should include:

* A home page
* An about section
* Your skills and technologies
* Your projects
* A contact section
* Responsive design
* A clear and accessible navigation system

For deployment, refer to [this portfolio deployment tutorial](https://youtu.be/kXtWjQowvVw?si=Iga5gNroIdObtZ3d) and deploy your portfolio using Vercel.

#### You should learn

* Next.js project structure
* File-based routing
* Pages and layouts
* Server and client components
* Data fetching
* Dynamic routes
* Metadata and SEO basics
* Image optimization
* Environment variables
* Production builds
* Deployment with Vercel

---

### 5. UI Libraries and Frameworks

Once you are comfortable with React and Next.js, explore libraries and frameworks that can help you create more polished, interactive, and visually engaging interfaces.

You do not need to learn all of these at once. Pick the tools that are useful for the project you are building.

#### 3D with Three.js

**Resource:** [Three.js Tutorial](https://youtu.be/lGokKxJ8D2c?si=0Y8P7iXJMqU7jbwT)

Three.js can be used to create interactive 3D experiences directly in the browser.

**Build:** Create a **3D Eye Model** that moves and follows the user's cursor.

#### You should learn

* 3D scenes
* Cameras
* Lighting
* Materials
* 3D models
* Animation
* User interaction
* Mouse and cursor tracking

#### Smooth Animations with Framer Motion

**Resource:** [Framer Motion Documentation](https://motion.dev/)

Framer Motion can be used to create smooth animations and interactions in React applications.

**Build:** Create a **Coffee Product Page** with smooth animations and interactive transitions.

#### You should learn

* Basic animations
* Transitions
* Hover animations
* Scroll animations
* Layout animations
* Gestures
* Page transitions

#### UI Libraries

Explore these libraries when you need reusable components, icons, or more visually engaging interfaces.

* **shadcn/ui** — Basic UI components such as buttons, cards, dialogs, carousels, forms, and more.
* **Aceternity UI** — Animated and visually engaging UI components and effects.
* **Lucide** — Clean and customizable icons.
* **React Icons** — A large collection of icon libraries for React applications.

The goal is not to memorize every library. Learn how to find, understand, customize, and integrate components into your own projects.
