# Web Development Roadmap

> A beginner-friendly path to learn the fundamentals of web development by learning, building projects, and gradually moving toward full-stack development.

## 🎯 Prerequisites

No prior web development experience is required.

You should be comfortable with:

* Using a computer and web browser
* Creating and managing files and folders
* Basic command-line usage is helpful, but not required

---

## 🗺️ Learning Path

### 1. HTML + CSS

#### Learn

[HTML + CSS Tutorial](https://youtu.be/HGTJBPNC-Gw?si=HWUpx1EZdUGjaZcI)

Start by learning how websites are structured and styled.

#### Build

Create a **Social Media Handles Page** containing links to all your social media profiles.

Try to make the page:

* Easy to navigate
* Responsive on different screen sizes
* Visually appealing
* Accessible and readable

#### You should learn

* HTML document structure
* Semantic HTML
* Headings, paragraphs, links, and images
* Forms and inputs
* CSS selectors
* Colors, fonts, spacing, and borders
* Flexbox
* Responsive design
* Basic accessibility

---

### 2. JavaScript

#### Learn

[JavaScript Tutorial](https://youtu.be/lfmg-EJ8gm4?si=3wX5i_pvYuZ4XJY7)

Learn how to make websites interactive and dynamic.

#### Build

Create a **Rock–Paper–Scissors game** where the user plays against the computer.

Your game should:

* Accept the player's choice
* Generate a random computer choice
* Determine the winner
* Keep track of the score
* Display the result clearly

#### You should learn

* Variables and data types
* Functions
* Conditional statements
* Loops
* Arrays and objects
* Events
* DOM manipulation
* User input
* Basic debugging
* Modern JavaScript syntax

---

### 3. React

#### Learn

[React Tutorial](https://youtu.be/CgkZ7MvWUAA?si=K3nSmS6DXptgOVv)

Once you are comfortable with JavaScript, learn React to build interactive user interfaces using reusable components.

#### Build

Create a **Pomodoro Timer** inspired by [Pomodoro Timer](https://pomodorotimer.online/).

Your timer should include:

* Work and break sessions
* Start and pause controls
* Reset functionality
* A visible countdown
* A clean and responsive interface

#### You should learn

* Components
* JSX
* Props
* State
* Event handling
* Conditional rendering
* Lists and keys
* Hooks
* Component composition
* Basic React project structure

---

### 4. Node.js

#### Learn

[Node.js Tutorial](https://youtu.be/ohIAiuHMKMI?si=tnGznMtYlGmMYW--)

> **Watch until video 35.**

Learn how JavaScript can be used on the server to build backend applications.

#### Build

Create a **To-Do List application with user sign-in**.

Your application should allow users to:

* Sign up and sign in
* Create tasks
* View their tasks
* Mark tasks as complete
* Delete tasks
* Keep each user's tasks separate

#### You should learn

* Node.js fundamentals
* npm
* HTTP and APIs
* Express.js
* Routing
* Middleware
* REST APIs
* Authentication
* Password handling
* Databases
* Environment variables
* Backend project structure
