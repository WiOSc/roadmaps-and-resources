# UI/UX Design Roadmap

A practical, project-based roadmap to learning UI/UX design, from understanding design fundamentals to creating polished, accessible, and user-centered digital products. Learn the principles, tools, and processes required to design websites and mobile applications, validate ideas through user research, and build a portfolio of real-world projects.

## Prerequisites

No prior design experience is required. Before starting, learners should have:

- Basic computer literacy and familiarity with websites and mobile applications.
- Curiosity about how people interact with digital products.
- Willingness to observe, experiment, accept feedback, and iterate on designs.
- Access to a design tool such as Figma.

## Learning Path

### 1. Introduction to UI/UX Design

#### Learn

- [What is the difference between UI and UX?](https://www.figma.com/resource-library/design-basics/)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)

#### Build

Choose an existing website or mobile application and analyze its user experience. Identify three usability problems, explain why they are problems, and suggest improvements.

#### You should learn

- Difference between UI design, UX design, and product design.
- Human-centered design and the design thinking process.
- Role of a UI/UX designer in a product team.
- Design process: Discover, Define, Ideate, Design, Test, and Iterate.
- Understanding users, their goals, and their pain points.

### 2. Design Fundamentals

#### Learn

- [Figma Design Basics](https://www.figma.com/resource-library/design-basics/)
- [Laws of UX](https://lawsofux.com/)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)

#### Build

Redesign a simple landing page using only typography, shapes, colors, and spacing. Create two variations and explain the design decisions behind each.

#### You should learn

- Visual hierarchy and Gestalt principles.
- Typography, font pairing, and readability.
- Color theory, contrast, and color palettes.
- Spacing, alignment, grids, and layout.
- Balance, proximity, consistency, and visual rhythm.
- UX principles such as Hick's Law, Fitts's Law, and Jakob's Law.
- Basic accessibility and color contrast.

---

### 3. Figma Fundamentals

#### Learn

- [Figma Design for Beginners](https://help.figma.com/hc/en-us/sections/30880632542743-Figma-Design-for-beginners)
- [Figma Learn](https://help.figma.com/hc/en-us)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)
- [Juxtopposed](https://www.youtube.com/@juxtopposed/playlists)

#### Build

Recreate a simple application screen from a reference design. Organize layers properly and create reusable buttons, input fields, and cards.

#### You should learn

- Figma interface, pages, frames, and layers.
- Shapes, text, images, and vector editing.
- Constraints, resizing, and alignment.
- Auto Layout and nested layouts.
- Components, instances, and variants.
- Styles and variables.
- File organization and naming conventions.

### 4. User Research and Problem Definition

#### Learn

- [Google UX Design Certificate](https://grow.google/intl/en_in/ux-design-course/)
- [Nielsen Norman Group - Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)
- [Juxtopposed](https://www.youtube.com/@juxtopposed/playlists)

#### Build

Choose a problem affecting students or everyday users. Interview at least five relevant people, identify recurring pain points, and document your findings in a short research report.

#### You should learn

- User interviews and surveys.
- Competitive analysis.
- Qualitative versus quantitative research.
- User personas and empathy maps.
- User stories and problem statements.
- Jobs to Be Done fundamentals.
- Affinity mapping and synthesis of research findings.
- Avoiding assumptions and leading questions.

---

### 5. Information Architecture and User Flows

#### Learn

- [Google UX Design Certificate](https://grow.google/intl/en_in/ux-design-course/)
- [Laws of UX](https://lawsofux.com/)
- [Juxtopposed](https://www.youtube.com/@juxtopposed/playlists)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)

#### Build

Create the information architecture and user flow for a campus event registration application. Map the journey from discovering an event to successfully registering for it.

#### You should learn

- Information architecture and content organization.
- User journeys and task flows.
- Navigation patterns and menu structures.
- Sitemap creation.
- Decision points, error paths, and edge cases.
- Reducing cognitive load.
- Designing intuitive navigation.

### 6. Wireframing and Low-Fidelity Prototyping

#### Learn

- [Google UX Design Certificate](https://grow.google/intl/en_in/ux-design-course/)
- [Figma Learn](https://help.figma.com/hc/en-us)
- [Juxtopposed](https://www.youtube.com/@juxtopposed/playlists)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)

#### Build

Create low-fidelity wireframes for a student productivity application. Include onboarding, a dashboard, task creation, task details, and a profile screen.

#### You should learn

- Sketching and rapid ideation.
- Low-fidelity versus high-fidelity wireframes.
- Screen hierarchy and content prioritization.
- Layout planning before visual styling.
- Clickable low-fidelity prototypes.
- Exploring and comparing alternative solutions.

### 7. UI Design and High-Fidelity Screens

#### Learn

- [Figma Design for Beginners](https://help.figma.com/hc/en-us/sections/30880632542743-Figma-Design-for-beginners)
- [Figma Design Basics](https://www.figma.com/resource-library/design-basics/)
- [Juxtopposed](https://www.youtube.com/@juxtopposed/playlists)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)

#### Build

Turn your wireframes into a polished, high-fidelity mobile application. Design a consistent visual language and create at least eight connected screens.

#### You should learn

- High-fidelity interface design.
- Design tokens and reusable styles.
- Typography scales and color systems.
- Buttons, forms, cards, navigation, and dialogs.
- Component variants and interactive states.
- Empty, loading, success, and error states.
- Responsive layouts and visual consistency.
- Designing for light and dark themes.

### 8. Interaction Design and Prototyping

#### Learn

- [Figma - Prototyping Fundamentals](https://help.figma.com/hc/en-us/articles/31010011820311-FD4B-Prototyping-fundamentals)
- [Figma Learn](https://help.figma.com/hc/en-us)
- [Juxtopposed](https://www.youtube.com/@juxtopposed/playlists)
- [Ansh Mehra UI/UX](https://youtube.com/playlist?list=PLlHtucAD9KT3wgeeVqILeW-0rYoQgR1Rh&si=XTdlxI1p2VA1rDNj)

#### Build

Turn your high-fidelity application into an interactive prototype. Connect screens, add realistic interactions, and demonstrate a complete end-to-end user journey.

#### You should learn

- Microinteractions and interaction patterns.
- Prototype connections and starting points.
- Overlays, modals, and scrolling behavior.
- Smart Animate and transitions.
- Feedback and system status.
- Form validation and interaction states.
- Designing interactions that feel natural and predictable.

---

### 9. Usability Testing and Iteration

#### Learn

- [Nielsen Norman Group - 10 Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)
- [Google UX Design Certificate](https://grow.google/intl/en_in/ux-design-course/)

#### Build

Test your prototype with at least five participants. Give them realistic tasks, observe where they struggle, document findings, and revise the design based on the evidence.

#### You should learn

- Usability testing and test planning.
- Writing unbiased task instructions.
- Observing behavior without leading participants.
- Identifying usability issues and their severity.
- Prioritizing improvements.
- Iterative design and feedback analysis.
- Measuring task success, errors, and completion time.

---

### 10. Responsive Design and Accessibility

#### Learn

- [W3C Web Accessibility Initiative](https://www.w3.org/WAI/)
- [Figma Auto Layout Guide](https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout-in-Figma)
- [Aman Mehra](https://www.youtube.com/playlist?list=PLlHtucAD9KT19ckHqXpPSStZOyDSq9AW-)

#### Build

Adapt one of your projects for mobile, tablet, and desktop. Audit the interface for accessibility issues and improve it.

#### You should learn

- Responsive and adaptive design.
- Breakpoints and flexible layouts.
- Desktop and mobile navigation patterns.
- Accessibility fundamentals and WCAG.
- Color contrast and readable typography.
- Keyboard navigation and focus states.
- Touch target sizes and clear labels.
- Designing for different abilities and contexts.

### 11. Design Systems and Advanced Figma

#### Learn

- [Figma Auto Layout Guide](https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout-in-Figma)
- [Figma Learn](https://help.figma.com/hc/en-us)
- [Aman Mehra](https://www.youtube.com/playlist?list=PLlHtucAD9KT19ckHqXpPSStZOyDSq9AW-)

#### Build

Create a small design system for a fictional product. Include design tokens, typography, colors, buttons, form fields, navigation elements, cards, and documentation explaining how to use them.

#### You should learn

- Atomic design principles.
- Component architecture and variants.
- Design tokens and variables.
- Component libraries and reusable patterns.
- Naming conventions and documentation.
- Maintaining consistency across screens.
- Designing scalable interfaces.
- Collaborating with developers and other designers.

### 12. Developer Handoff and Portfolio

#### Learn

- [Figma Learn](https://help.figma.com/hc/en-us)
- [Google UX Design Certificate](https://grow.google/intl/en_in/ux-design-course/)
- [Aman Mehra](https://www.youtube.com/playlist?list=PLlHtucAD9KT19ckHqXpPSStZOyDSq9AW-)

#### Build

Document one complete case study from problem discovery to final design. Prepare your Figma file for handoff and publish the case study in a personal portfolio.

#### You should learn

- Developer handoff and design specifications.
- Exporting assets and organizing components.
- Communicating interaction behavior and edge cases.
- Explaining design decisions with evidence.
- Structuring a UX case study.
- Presenting research, iterations, and outcomes.
- Building a portfolio and preparing for design interviews.

## Projects

### Beginner

- **Landing Page Redesign:** Improve the visual hierarchy, spacing, typography, and responsiveness of an existing landing page.
- **Music Player UI:** Design a music player with playback controls, a queue, and reusable components.
- **Student To-Do App:** Design task creation, completion, and filtering screens.
- **Design Recreation:** Recreate an existing interface in Figma to practice spacing, layout, and visual accuracy.

### Intermediate

- **Campus Event Discovery App:** Design an end-to-end experience for finding and registering for college events.
- **Expense Tracker:** Design dashboards, transaction lists, filters, and expense-entry flows.
- **Food Ordering App:** Design restaurant discovery, menu browsing, cart management, and checkout.
- **UX Audit:** Evaluate an existing product, conduct user research, and propose evidence-based improvements.

### Advanced

- **End-to-End Product Case Study:** Identify a real user problem, conduct research, define requirements, prototype a solution, and validate it through testing.
- **Design System:** Build a reusable component library with tokens, variants, accessibility considerations, and documentation.
- **Responsive SaaS Dashboard:** Design a complex dashboard with tables, filters, data visualizations, empty states, and responsive layouts.
- **Redesign with Validation:** Select an existing digital product, identify a specific usability problem, redesign the affected flow, and test whether the new version improves task completion.

## Completion Checklist

- [ ] Understand the distinction between UI, UX, and product design.
- [ ] Learn the fundamentals of visual design and usability.
- [ ] Become comfortable with Figma and reusable components.
- [ ] Conduct user research and define a real problem.
- [ ] Create user flows, sitemaps, and wireframes.
- [ ] Design polished high-fidelity interfaces.
- [ ] Build an interactive prototype.
- [ ] Conduct usability testing and iterate on the design.
- [ ] Apply responsive design and accessibility principles.
- [ ] Create a documented design system.
- [ ] Prepare a developer-ready Figma file.
- [ ] Complete at least two smaller projects and one end-to-end case study.
- [ ] Publish a portfolio with clear explanations of design decisions.
